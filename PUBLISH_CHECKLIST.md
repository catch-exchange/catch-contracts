# Publication checklist

The repeatable process is in [Maintaining the public source record](docs/RELEASING.md).

- [ ] Only the reviewed public checkout and clean history are pushed.
- [ ] No private credentials, launch material, recovery logs or future families.
- [ ] Sources/inputs, ABIs and all eight compiler outputs reproduce.
- [ ] Integrity tests and working-tree/full-history secret scans pass.
- [ ] Public identities and evidence limitations are reviewed.
- [ ] CI passes at the exact commit; tag/release refers to that commit.
- [ ] Unauthenticated README, source, deployment and release links work.
- [ ] Site links and submissions use the actual public version.

No audit, fresh chain reconciliation, Sourcify full match or router admission
is inferred from publication checks.
