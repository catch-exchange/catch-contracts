# Artwork

`catch-market-standard.png` is the existing approved Catch marble-mark
illustration used in the public technical paper. It is copied without editing;
1672 × 941 pixels. It is branding, not an audit badge, economic chart or live
market representation. No private article drafts or source artwork are included.

The publication check pins its SHA-256 and PNG signature. Only this exact image
is allowed; the repository does not generally permit binary uploads.
